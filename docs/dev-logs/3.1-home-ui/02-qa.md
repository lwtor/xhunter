## 2026-06-03 16:17 · Q1：`Icons.Filled.Category` 找不到

### 问题

按 spec 第 2.1 节改 `MainTab.kt`，写 `Icons.Filled.Category` 时 IDE 报「找不到」/「Unresolved reference: Category」。

### 原因

`Icons.Filled.Category` 属于 **material-icons-extended**（扩展图标包），默认 Compose Material3 只带 core 图标包（约几十个常用图标），`Category` 不在 core 里。

spec 第 8 节「风险点」里其实预警过这个情况，本次确认命中。

### 解决方案对比

| 方案 | 做法 | 代价 | 推荐度 |
| --- | --- | --- | --- |
| **1. 换成 core 包里的现成图标** | 用 `Icons.Filled.GridView` 替代 | 零成本 | ⭐⭐⭐⭐⭐ |
| 2. 引入 material-icons-extended | 加 `implementation(compose.materialIconsExtended)` | APK +10MB 左右（debug 包尤甚） | ⭐⭐ |
| 3. 临时图标，后续步骤批量引 extended | 本步先用 GridView，等真正需要大量扩展图标的步骤再引依赖 | 零成本 + 灵活 | ⭐⭐⭐⭐ |

### 最终决定

采用 **方案 1**：用 `Icons.Filled.GridView`。

**理由**：

- `GridView` 是九宫格图标，视觉语义与"分类"贴合度高
- core 包内置，零依赖成本
- 未来如果整体引入了 extended 包想换回 `Icons.Filled.Category`，也只是改一行 import + 一行赋值的事

### 落地代码（`MainTab.kt`）

```kotlin
package com.lwtor.xhunter.ui.main

import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Favorite
import androidx.compose.material.icons.filled.GridView
import androidx.compose.material.icons.filled.Home
import androidx.compose.material.icons.filled.Search
import androidx.compose.ui.graphics.vector.ImageVector

enum class MainTab(
    val label: String,
    val icon: ImageVector,
) {
    HOME(label = "主页", icon = Icons.Filled.Home),
    FAVORITES(label = "收藏", icon = Icons.Filled.Favorite),
    EXPLORE(label = "发现", icon = Icons.Filled.Search),
    CATEGORIES(label = "分类", icon = Icons.Filled.GridView),
}
```

### Spec 同步修订

spec 第 2.1 节、第 8 节中提到的 `Icons.Filled.Category` 默认改成 `Icons.Filled.GridView`，此次答疑作为最终决定。

## 2026-06-03 16:19 · Q2：`Icons.Filled.GridView` 也找不到

### 问题

按 Q1 的方案改成 `Icons.Filled.GridView` 后，IDE 仍然报「Unresolved reference: GridView」。

### 原因

Compose Material core 图标包实际仅包含约十几个最常用图标（Home / Favorite / Search / Person / Settings / Menu / Add / Close / Check / ArrowBack / MoreVert / Info / Warning / Star 等），`GridView` 在不同 compose 版本里归属不一致——当前工程的 `compose.material3` 版本下，`GridView` 仍在 extended 包里，core 里取不到。

我（AI）在 Q1 推荐时对 core 包覆盖范围估计偏乐观，向你说声抱歉。

### 用户最终选择

直接改用 **`Icons.Filled.Menu`**（汉堡菜单图标），core 包必带，编译通过。

### 落地代码（`MainTab.kt` 最终版）

```kotlin
package com.lwtor.xhunter.ui.main

import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Favorite
import androidx.compose.material.icons.filled.Home
import androidx.compose.material.icons.filled.Menu
import androidx.compose.material.icons.filled.Search
import androidx.compose.ui.graphics.vector.ImageVector

enum class MainTab(
    val label: String,
    val icon: ImageVector,
) {
    HOME(label = "主页", icon = Icons.Filled.Home),
    FAVORITES(label = "收藏", icon = Icons.Filled.Favorite),
    EXPLORE(label = "发现", icon = Icons.Filled.Search),
    CATEGORIES(label = "分类", icon = Icons.Filled.Menu),
}
```

### 备注

`Icons.Filled.Menu` 是汉堡菜单语义，不是最贴"分类"，但本步不在图标上纠结。后续步骤（plan 第 7 步设置 / 第 8 步源管理）若整体引入 `compose.materialIconsExtended` 依赖，可以一次性把"分类" Tab 的图标换回 `Icons.Filled.Category`，作为视觉小优化。

### 经验教训（写给 AI 自己）

下次推荐 core 包内图标时，应**只敢推荐高确定性图标**：Home / Favorite / Search / Person / Settings / Menu / Add / Close / Check / ArrowBack / MoreVert / Info / Star。不在这个清单里的（包括 GridView / Apps / Category / List / Explore 等），都应该按"可能不在 core 里"提示，并给出"找不到就用 Menu 兜底"的备案。
